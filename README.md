# Voice Shield (laptop version)

Detects AI-cloned voices in live speech or uploaded clips, in Hindi and English.
This is Stage 1 of the build plan: everything runs on the laptop, and the server
already speaks Twilio's Media Streams format so it can take real calls later.

## Folders

| Folder | What is in it |
|---|---|
| `vs/` | Core code: audio clean-up, phone simulation, the XLS-R + SLS model, live-call session, verdict messages |
| `server/` | FastAPI server (upload scoring + live WebSocket) |
| `web/` | Laptop test page served by the server |
| `tools/` | Scoring our own test set, building the Kaggle notebook |
| `training/` | Kaggle notebooks (generated by `tools/build_kaggle_notebook.py`) |

## Run on the laptop

From this folder, in PowerShell:

```powershell
py -3.14 -m venv .venv
.venv\Scripts\python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn server.app:app --port 8000
```

Open http://localhost:8000 in Chrome or Edge. The first start downloads the
checkpoint (about 1.3 GB) from HuggingFace, so wait until the page says
**Model ready**.

## Score our own test set

Put clips in `test_set/clips/` and list them in `test_set/labels.csv`:

```
file,label,language,source
clips/ansh_hi_01.wav,real,hi,team
clips/ansh_hi_01_xtts.wav,fake,hi,xtts
```

```powershell
.venv\Scripts\python tools\score_folder.py test_set\labels.csv
```

It prints EER per language for clean and phone mode, and saves every score to
`results/scores.csv`.

## Kaggle notebooks

```powershell
.venv\Scripts\python tools\build_kaggle_notebook.py
```

This rebuilds `training/01_baseline_in_the_wild.ipynb` (baseline check) and
`training/02_finetune_hindi_phone.ipynb` (fine-tuning). Our code is embedded in
them as `%%writefile` cells, so on Kaggle you only import the notebook, attach
the datasets listed at its top, and run. Re-run the builder after changing
anything in `vs/`.

To use a fine-tuned model on the laptop, put the `.pth` file in `models/` and:

```powershell
$env:VS_CHECKPOINT = "models\voice_shield_ft.pth"
.venv\Scripts\python -m uvicorn server.app:app --port 8000
```

## Model

XLS-R 300M + SLS classifier (Zhang et al., ACM MM 2024), public checkpoint
`sukhdeveyash/XLS-R-SLS-Deepfake-Detection` (`v1/epoch_2.pth`, MIT licence,
reported 7.84% EER on In-the-Wild). The checkpoint was trained with fairseq;
`vs/model.py` rebuilds the same network on HuggingFace `transformers` and
converts the weights when loading.
